# 견적 자동화 고객 획득·결제 구조

## 현재 상태

- 매출: 0원
- 실제 고객 후기: 0개
- 작동 납품 코드: 있음
- 브라우저 데모: 있음
- 판매 페이지·신청 동선: 있음
- 마켓 판매자 등록·안전결제: 아직 없음
- 유료 광고: 아직 없음
- 고객이 먼저 요청한 프로젝트 제안: 아직 없음

따라서 현재는 **판매 준비 단계**이며 자동으로 돈이 들어오는 구조는 아니다.

## 해결하는 문제

고객: 월 5건 이상 맞춤 견적을 보내는 1~10인 행사·렌탈·교육·제작 서비스업.

문제:

1. 문의 내용을 견적서에 다시 입력한다.
2. 지난 문서를 복사하면서 품목·금액 오류가 생긴다.
3. PDF 저장, 이메일 제목·본문, 첨부를 반복한다.
4. 견적 발송 뒤 다시 연락할 날짜를 놓친다.

이 문제는 견적이 매출 직전 단계라서 일반적인 ‘업무 효율’보다 구매 이유가 분명하다.

## 제공 서비스

고객의 Google 계정 안에 다음 흐름을 맞춤 구축한다.

`문의/고객 한 행 입력 → 품목·단가 계산 → 기존 양식 견적 PDF → Gmail 초안 → Calendar 후속 연락 → 일일 확인 요약`

고객 메일은 자동 발송하지 않는다. 담당자가 금액·수신자·첨부를 확인한 뒤 보낸다.

## 신뢰를 만드는 순서

### 1. 일반 데모 — 무상

브라우저에서 입력값을 바꾸며 견적서와 이메일 초안 결과를 확인한다. 서버 저장은 없다.

### 2. 자기 회사용 1분 샘플 — 무상, 관심 표현 후 제공

잠재고객이 먼저 샘플을 요청하면 공개 품목 또는 고객정보를 가린 견적서로 자기 회사명이 들어간 흐름을 보여준다. 콜드 메일로 무단 발송하지 않는다.

### 3. 호환성 확인 — 무상

월 건수, 현재 흐름, Google 사용 가능 여부, 필수 연동을 확인한다. 맞지 않으면 구매를 권하지 않는다.

### 4. 고정 범위·안전결제 — 유료

마켓 플랫폼에서 포함·제외 범위와 납기를 합의하고 안전결제로 주문받는다. 판매자 등록 전에는 이 단계가 열리지 않는다.

### 5. 납품·인수인계·후기 — 유료 완료

필수자료와 권한 수령 후 구축, 샘플 테스트, 화면 공유, 오류 수정. 만족한 고객에게만 솔직한 후기를 요청한다.

## 고객을 데려오는 합법적 채널

1. **크몽 서비스 등록**: `견적서 자동화`, `구글시트 자동화`, `Apps Script` 검색 수요를 받는다. 플랫폼 안전결제로 첫 구매의 불안을 낮춘다.
2. **위시켓·크몽 엔터프라이즈 공개 프로젝트**: 클라이언트가 자동화 외주를 명시적으로 요청한 건에만 지원한다.
3. **네이버 검색광고**: `견적서 자동화`, `엑셀 견적서 자동화`, `구글시트 견적서` 키워드에서 데모로 유입시킨다. 계정과 광고비 승인이 필요하다.
4. **허용된 커뮤니티 글**: 홍보 게시판 또는 운영자 허가가 있는 곳에만 문제 해결형 글과 데모를 올린다.
5. **검색 콘텐츠**: “견적서를 보내고 후속 연락을 놓치는 이유” 같은 구체적인 업무 글에서 데모로 연결한다.
6. **추천**: 첫 납품 후 동일 업종 소개 1곳을 요청한다.

## 사용하지 않는 채널

- 공개 이메일을 수집해 사전동의 없이 영업 메일 전송
- 고객 문의 폼을 영업 제안용으로 사용
- 자동 DM, 대량 댓글, 연락처 자동 생성
- 가짜 후기·가짜 수량 제한·검증되지 않은 절감시간

KISA는 거래관계 등 예외가 없는 사전동의 없는 광고성 정보 전송을 금지한다고 안내한다. 참고: <https://spam.kisa.or.kr/spam/cm/cntnts/cntntsView.do?cntntsId=1086&mi=1061>

## 숫자로 보는 매출 경로

목표 총매출은 550,000원 표준 구축 2건 = 1,100,000원이다.

그러나 후기 0개 상태에서 72시간 내 2건은 보장할 수 없다. 검증할 가설은 아래다.

| 단계 | 1차 목표 | 실제 기록 |
|---|---:|---:|
| 마켓 상세페이지 노출/검색 유입 | 100 | 0 |
| 데모 방문 | 25 | 0 |
| 호환성 신청/프로젝트 답장 | 5 | 0 |
| 자기 회사용 샘플 | 3 | 0 |
| 결제 | 2 | 0 |
| 총매출 | 1,100,000원 | 0원 |

이 표에서 실제 전환을 기록해야 구조가 검증된다. 페이지 제작만으로는 검증된 수익 구조라고 부르지 않는다.

## 지금 필요한 외부 권한

- 크몽 또는 다른 안전결제 마켓의 판매자 계정 로그인·본인/사업자 인증
- 등록 버튼을 누르기 전 판매자명, 증빙 방식, 정산 계좌 확인
- 네이버 검색광고를 쓸 경우 계정 로그인과 일일 예산 승인

이 권한 없이 가능한 일은 상품·데모·등록 원고·이미지·지원서 준비와 공개 프로젝트 모니터링까지다.
