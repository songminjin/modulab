# 문의 → 견적 → 후속 연락 자동화

1인 사업자와 소규모 서비스 회사가 반복하는 다음 흐름을 Google Sheets 안에서 처리합니다.

1. 견적 요청과 고객 정보를 한 행으로 기록
2. 견적항목을 견적번호로 연결
3. 버튼으로 견적 PDF 생성
4. PDF가 첨부된 Gmail 초안 생성
5. 다음 연락일을 Google Calendar에 기록
6. 매일 확인할 후속 연락을 대표자 이메일로 요약

## 안전 원칙

- 고객에게 메일을 자동 발송하지 않습니다. Gmail 초안을 사람이 검토한 뒤 발송합니다.
- 고객 데이터는 설치한 사용자의 Google 계정 안에서 처리합니다.
- 실제 고객정보를 전달하기 전에 마스킹한 샘플 데이터로 검증합니다.
- 세금계산서 발행, 결제, 가격 결정, 카카오 알림톡, 외부 사이트 스크래핑은 포함하지 않습니다.

## 설치

1. 빈 Google Sheets를 만듭니다.
2. `확장 프로그램 → Apps Script`를 엽니다.
3. `Code.gs` 내용을 붙여넣고 저장합니다.
4. `setupQuoteSystem`을 처음 한 번 실행하고 권한을 승인합니다.
5. 스프레드시트를 새로고침합니다.
6. `견적 자동화 → 선택 행 견적 만들기`를 실행합니다.

처음 설정은 `견적요청`, `견적항목`, `단가표`, `설정` 시트와 Google Docs 견적 템플릿, 출력 폴더를 만듭니다.

## 맞춤 구축 범위

- 기존 견적서 양식 반영
- 품목·옵션·할인·부가세 규칙 반영
- 문의 폼과 견적요청 시트 연결
- Gmail 제목·본문 문구 반영
- 후속 연락 규칙과 담당자 알림 반영
- 화면 공유 인수인계와 7일 오류 수정

업종·양식·외부 서비스에 따라 가능 범위가 달라지므로 결제 전 마스킹한 샘플로 호환성을 확인합니다.
