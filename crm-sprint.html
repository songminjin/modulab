FAQ

결제 전에 꼭 확인하세요

어떤 업종에 가장 잘 맞나요?

보험, 부동산, 학원, 컨설팅처럼 문의 이후 재상담과 일정 관리가 계약에 중요한 업종에 특히 잘 맞습니다. 무료 진단에서 현재 흐름에 적합한지 먼저 판단합니다.

정말 48시간 안에 완성되나요?

합의한 핵심 흐름 하나를 기준으로 하며, 결제와 필수 정보 전달이 모두 끝난 시점부터 48시간입니다. 추가 기능이나 외부 서비스 승인 지연은 별도 일정으로 합의합니다.

고객 데이터와 API 키는 누가 관리하나요?

가능하면 고객 소유 Google 계정에서 운영하며, API 키와 데이터 접근권한도 고객이 관리합니다. 불필요한 개인정보는 수집하지 않습니다.

효과가 없으면 환불되나요?

매출 성과 자체는 보장하지 않습니다. 착수 전에는 전액 환불하고, 착수 후에는 합의한 작업 범위와 실제 진행 단계에 따라 협의합니다. 기능 작동 오류는 납품 후 7일간 수정합니다.
